# 银龄复诊事项协同助手 — 用户手册

> **文档版本：** v0.2
> **更新日期：** 2026年9月11日

> 适用范围：已成功启动并打开本系统的用户。本文不讲解如何安装与部署，启动方法见 [README](../README.md)。
> 本文所述均为**比赛演示功能**：医院、用户、号源、路线和通知都是模拟数据，不连接真实医院，也不提供诊断或用药建议。

## 一、这是什么

**银龄复诊助手** 是一款适合银发用户使用的复诊事项协同办理小工具。您用一句话或按提示点选，它就会一步一步帮您完成：

预约医院 → 选择科室与时间 → 整理要带的材料 → 检查日程是否冲突 → 安排出发时间 → 创建复诊提醒 → 通知家属

全程采用**手机卡片式界面**：大字号、高对比，每次只问一件事，点大按钮即可操作；关键动作（预约、取消、通知家属）都会先在卡片上列清楚，经您**明确确认**后才执行。

> 界面以手机宽度呈现，建议用手机尺寸的浏览器窗口或模拟器打开。

## 二、页面总览

打开系统先看到**身份选择页**：请选择「就诊人本人」「家属」「志愿者」三者之一，选完进入对应的界面。

- **就诊人本人**：进入就诊人端，底部固定四个标签，可随时点按切换。
- **家属 / 志愿者**：进入**协同照护端**，底部同样是四个标签，用于查看和照护长辈的复诊（详见第七章）。

就诊人端右上角常驻一个 **「人工帮助」** 按钮（演示环境为模拟入口，不接真人；点击会提示信息已保留）。

| 标签 | 页面 | 作用 |
| --- | --- | --- |
| **首页** | 问候 + 复诊入口 + 提醒与记录入口 | 显示下一次复诊（或"暂无预约"），进入助手；并汇总到点提醒、长期备忘与健康记录 |
| **事项** | 我的复诊事项 | 查看预约记录、复诊材料清单，并可把材料逐项标记为"已准备" |
| **助手** | 复诊助手 | 核心办理界面，与助手对话完成预约、记健康数值、设提醒等全流程 |
| **我的** | 个人资料与适老设置 | 查看用户资料与家属联系人；开关"特大字体""语音朗读" |

协同照护端四个标签：

| 标签 | 页面 | 作用 |
| --- | --- | --- |
| **首页** | 协同首页 | 长辈服务入口、需要关注的动态、我协同的长辈总览 |
| **消息** | 协同消息 | 按长辈聚合的通知 |
| **助手** | 协同助手 | 与同一个助手对话，查长辈的复诊、代约、给长辈留提醒 |
| **我的** | 我的 | 切换身份、我协同的长辈、设置入口 |

每个页面的顶部都有返回箭头和「人工帮助」。

## 三、首页

选完身份（就诊人本人）即进入首页，从上到下为：

1. **问候与用户名**：右上角有「人工帮助」按钮。
2. **健康备忘提醒横幅**（到点时出现）：显示到点的提醒内容与提醒时间，点 **「知道了」** 收起本次（重复提醒下一轮到点仍会再弹）。
3. **办理入口卡片**：写着"想办理复诊，直接跟我说"。点击 **「按住说话，开始办理」** 跳转到助手页。
4. **下一次复诊**：
   - 若已有确认的预约，会显示日期、时间、医院科室和提醒状态卡片，点卡片可去"事项"页看详情；
   - 若还没有预约，显示"暂无复诊预约"，点它可直接去助手办理。
5. **常用服务**：**检查材料** 与 **出行安排** 两个快捷入口。已预约时进入事项页查看，未预约时引导去办理。
6. **提醒**：显示最近一条到点提醒；多于一条时可点 **「查看全部提醒」** 进入提醒列表，逐条查看、修改、删除或标记已完成。
7. **长期备忘**：点 **「查看长期备忘」** 进入长期备忘列表（显示条数）。
8. **健康记录**：点 **「查看健康记录」** 进入健康记录页（显示条数）。
9. 底部一行小字：**"当前内容均为比赛演示数据"**。

## 四、复诊助手（核心）

这是最主要的使用界面。点底部 **「助手」** 标签进入（首次进入会自动开启一段新会话）。

### 4.1 界面构成

自上而下依次是：

- **顶部栏**：标题"复诊助手"，副标题"一次只问一件事"；左侧返回（首页），右侧两个按钮 **「历史记录」**（翻看以前聊过的）与 **「新对话」**（结束这段、重新开始）。
- **当前步骤条**：如"当前步骤：确认医院"。这是系统此刻在等您回答什么。
- **两个快捷按钮**：**「预约复诊」**（重新开始/继续办理）和 **「事项查询」**（跳事项页）。
- **「返回修改」「取消办理」** 两个操作按钮，随时可用。
- **对话记录区**：您说的话与助手的回复，一上一下排列。
- **动态卡片**（视进度出现）：**复诊办理计划**、**关键操作确认**、**复诊事项卡**、**工具调用记录（"查看办理过程"）**。
- **「查看办理过程」是活的**：助手在思考、在查东西的那几秒里，卡片上会一条条长出来——"正在理解您说的话…"、"正在决定要不要查东西…"、"调用工具：××"、"拿到结果：××"。查到的内容就是这一轮真的查到的，不是提前写好的；这一轮结束后卡片自动收起。
- **快捷回答**：屏幕下方的圆角按钮，最多同时显示 3 个；选项超过 3 个时会出现 **「查看更多选项」**。
- **输入区**（固定在底部）：中间输入框和右侧 **「发送」** 按钮；大麦克风固定悬浮在底部导航中央，在首页、事项、助手和出行页面保持同一位置。

### 4.2 两种说话方式

- **打字**：点输入框（占位文字"也可以在这里打字"），输入后点蓝色 **发送**。
- **按住说话**：按住底部中央的大麦克风说话，松手后自动发送。普通页面口令由当前页面处理；其他问题会自动转到助手继续对话。
- 语音期间按钮会变红，屏幕中下方弹出浮层写着“正在听您说话…”，里面那排音量条跟着您的声音起伏；说话时上滑可以取消，滑回来还能接着说。识别失败使用临时提示，不会把重复错误写入聊天记录。

### 4.3 正常办理流程

助手会**一次只问一个问题**。请按下面顺序提供信息，可以直接打字整句回答（如"市第一医院，心内科，下周复诊"），也可以点下方的快捷按钮。

1. **选医院**：问"想去哪家医院复诊？"——点按钮选一家模拟医院（例如"市第一医院（模拟）"），或直接打字说出医院名。
2. **选科室**：列出这家医院可办理的科室（如心内科、神经内科）。点选医生要求复诊的科室。
3. **选日期**：列出几个可办理日期，直接点；也可以自己说日期（如"9 月 18 日"）。已过去的日期会被拒绝并提示重选。
4. **选时间**：助手查询真实模拟号源后，问"您想上午去还是下午去？"。选择上午/下午后，它会推荐该时段**最早**的号并问"这个时间可以吗？"。可回：
   - **"这个时间可以"**——采纳推荐时间；
   - **"看看其他上午/下午时间"**——列出该时段所有可选时间再选；
   - 也可以说具体时间（如"下午两点半"），它会给出最接近且有号的时间供确认。
5. **回答补充问题**（各一题、都可点选）：
   - 这一天没号时，先问"接受附近的其他日期吗"（可换日期 / 只要这一天）；
   - "需要家属陪同吗？"（需要 / 不需要）；
   - "需要我计算出发时间并提醒吗？"（需要出行提醒 / 不需要）；
   - "您准备怎样去医院？"（家属开车 / 打车 / 公交）；
   - "需要通知家属吗？"（需要 / 不用）；若需通知，再点选要通知哪位家属（如"女儿 小丽"）。
   - 模拟演示中家属已配置为"女儿 小丽"。
6. **生成计划并检查日程**：所有信息齐备后，助手自动整理材料、检查所选时间是否与已有日程（如"社区体检"）冲突，并计算出发建议；这一步只读，不会提交预约，因此不再要求额外点击 **「开始办理」**：
   - **无冲突**：直接进入确认卡；
   - **有冲突**：说明冲突事项与起止时间，请改选其它号源，或明确点 **「仍保留这个时间」**。
7. **关键操作确认卡**：助手先用文字和语音完整复述医院科室、复诊日期时间、陪同需求、建议出发、材料、拟创建提醒和通知对象，同时展示标题为 **"请确认复诊办理计划"** 的确认卡。确认前说“打开地图”不会清除或绕过确认卡；必须明确说 **“确认办理”** 或点击对应按钮才会执行写操作。
   - 点 **「确认办理」** → 依次执行预约、创建提醒、通知家属；
   - 点 **「返回修改」** → 取消本次执行，回到计划卡可继续调整。
   > 助手页另提供 **「返回修改」「取消办理」** 按钮，可随时放弃当前草稿或取消已确认的预约（见第八、九章）。
8. **复诊事项卡**：办理完成后弹出绿色 **"办理完成"** 卡片（部分步骤失败时标题为 **"预约已保留，部分事项待补办"**），包含：复诊日期时间、医院科室、**建议出发时间**、提醒状态、**家属通知状态**、**携带材料**清单、模拟预约编号。下方可 **查看事项**。

> **页面刷新与恢复**：会话会自动保存在浏览器里。中途刷新或关闭再打开，进入"助手"页会**恢复上次那一段对话**与当前计划，不会丢进度。若上次那段已经结束，则直接开始新的一段，不会让您停在一个打不了字的页面上。若后端重启导致无法恢复，会提示重新连接，可点 **「重新连接」**。

### 4.6 历史记录与新对话

点顶部 **「历史记录」** 打开浮层，里面是您最近聊过的几段，**新的在最上面**。每一行显示：

- 这段是从哪句话开始的（取您说的第一句）；
- 状态：**进行中** / **已结束** / **很久没聊**；
- 上次说话是什么时候（"刚刚""12 分钟前""昨天 15:20""3 天前"）；
- 这一段一共多少条消息；
- 当前正在看的那一段会标出来。

点一行就切过去。**已经结束的会话只能翻看**：消息照常显示，输入框会换成一条说明和一个 **「开始新的一段对话」** 按钮——不把输入框摆在那儿让您打完字才被拒绝。

点 **「新对话」** 会先结束当前这一段，再开一段新的。**旧的那段不会被删掉**，随时能从历史记录里点回来。

如果一段时间没来（比如隔了很久），这段会话会被标成"很久没聊"，但**您之前填到一半的内容还在**：再说话就能接着办，待确认的卡也还在，不用从头再来。

### 4.7 朗读设置（音色与语速）

助手页下方有一块可以展开的 **「朗读设置」**：

- **朗读音色**：从可用的音色里挑一个。后端没有开启云端朗读时，这一项会置灰并说明"这时会用手机自带的语音念给您听，能正常朗读"——**念不出来这件事不会发生**，只是音色不可选。
- **语速**：滑条调整，范围 0.5 倍到 2 倍，调完自动保存。
- **试听**：点一下念一句样例；再点一次是**重新念**，不是停止。

朗读本身有两条路：优先用手机自带的语音（不联网也能用），配了云端语音时用云端合成，失败会自动退回手机语音。助手每条回复旁边的喇叭按钮可以单独播放或停止；正在念的时候点另一条，会先掐掉上一条。

### 4.4 自由表达

不必按固定顺序。助手理解整句口语并分轮收集信息，例如直接说：

> "我下周三想去看心内科复诊，出发前提醒我，并告诉女儿。"

系统会提取医院、科室、时间等信息，仍缺的项会一项一项补问，绝不凭空生成办理结果。也可以用自然语言**中途改医院/改日期**、**问医院与科室资料**、**要材料清单**，以及把需求拆成多轮说。

### 4.5 关键操作确认卡

出现本卡片表示系统即将执行**会留下记录**的操作。请务必看清每一条：要办什么、在哪家医院哪个科室、什么时候、要提醒谁、要通知谁、可能有什么影响，再点 **确认办理**。点 **返回修改** 则不执行。卡片下方不设含义模糊的按钮。

## 五、事项页

点底部 **「事项」** 标签进入。预约成功后，医院、时间、材料和提醒都会汇总在这里。

- **预约记录列表**：顶部"我的复诊预约记录"按卡片列出每次预约（日期、时间、医院 · 科室、**已预约/已取消** 状态）。点另一条可切换查看。系统自动选中状态为"已预约"的那条；没有已预约时选中最近一条。
- **当前预约概览**：橙色卡片，展示所选预约的复诊时间、医院科室与建议出发时间（如"建议 08:30 出发"）；未设出行提醒时显示"未设置出行提醒"。
- **材料清单**：列出复诊要带的材料（如身份证、医保卡、上次就诊病历等，标"必带"的是必带项）。**点一下某项即可标记为已准备**，顶部实时显示"已准备 x/n"进度。此标记仅本页查看时有效，用于提醒自己别漏带。
- **提醒与家属通知状态**：底部两行卡片，分别显示"复诊及出发提醒已创建"等提醒结果，以及家属通知结果（如"已通知女儿 小丽"）；未选择通知时显示"无需通知家属"。
- 若还没有任何复诊事项，页面会引导"让助手帮我预约"。

## 六、健康记录与健康备忘

除复诊外，助手还能帮您记下日常的健康数值和要做的事。相关入口都在首页底部。

### 6.1 健康记录

- 跟助手说一句 **「我的血压是100」**，它就帮您记一条**实测数值**（血压、血糖等）。数值明显异常时，系统会**先反问**（重测还是照记），不会直接落库。
- 首页「健康记录」可查看全部记录：按测量时间倒序、按月分段，可一直往前翻。
- 记录页顶部可以把一段记录**汇总发给家属**：点「发给家属」后选择「最近一周」或「最近一个月」。是否发出以模拟数据库实际执行为准，页面会如实回话。

### 6.2 健康备忘

- **到点提醒**：说「明早八点提醒我吃药」，到点会在首页弹出「健康备忘提醒」横幅，点「知道了」收起本次。
- **长期备忘**：只记下、不到点提醒的事（如「药盒放在抽屉里」），从首页「长期备忘」查看。
- 备忘支持**每天 / 每周 / 每月**重复，也可以只提醒一次；可以查、改时间、删。卡片上有「修改」「删除」；到点提醒的还多一个「已完成」。

> 说「明早八点提醒我吃药」是给自己**记一条备忘**；家属说「提醒我妈明天带身份证」是**给长辈留提醒**（见 7.3）——两者不一样：后者的落点是长辈自己的备忘，并标明是谁留的。

## 七、协同照护端：家属与志愿者

在身份选择页选「家属」或「志愿者」进入协同照护端。它与就诊人端**共用同一个助手智能体**，用来照护长辈的复诊。

### 7.1 四个标签

- **首页**：长辈服务入口（**帮助预约** / **就诊动态** / **复诊预约** / **长辈信息**）、需要关注的动态提示、我协同的长辈总览（显示每位长辈最近一次预约）。
- **消息**：按长辈聚合的通知，纯展示。
- **助手**：与助手对话，见 7.3。
- **我的**：切换身份、我协同的长辈清单、设置入口（设置项为后续版本预留）。

> 若您名下绑定了多位长辈，进入「就诊动态 / 复诊预约 / 长辈信息」前会先让您选一位；「帮助预约」总是先选长辈，明确这一轮替谁办。

### 7.2 帮助预约（代他人办理）

点首页「帮助预约」，按 **医院 → 科室 → 日期号源 → 确认** 四步替长辈约好复诊，最后的确认按钮是 **「确认代约」**。

- 若长辈名下**已有进行中的预约**，会先停在该预约的**管理视图**：可「查看详情」、「修改」（走同一套向导，按钮变为「确认修改」）、或「取消这次预约」（需在展开的卡片里再点「确认取消」）。要重新代约，需先取消已有预约。
- **陪同**：「会陪同 / 不陪同」记录您本人是否参与这次复诊；只有确认陪同的照护者才会在预约卡片上看到出发建议。
- 可打开「按计划出发当天提醒」，并选择打车 / 公交 / 家属开车。

### 7.3 助手的三种用法

1. **查询**：长辈的复诊安排、需要带的材料、最近的就诊动态。
2. **代约**：用对话替长辈预约复诊，同样走确认卡。
3. **留提醒**：如「提醒我妈明天带身份证」，这条会落进**长辈自己的备忘**里，并标明是您留的。

代约的确认卡会明确列出：

- **服务对象**：本次替哪位长辈办理；
- **代约归属**：这份预约记为由您代约，并会通知其他照护者。

代他人办理时**不问「通知哪位家属」**——您本人就是被通知方，代约本身会通知其他照护者。

## 八、修改与取消

办理过程中随时可点助手下方的 **「返回修改」** 或 **「取消办理」**，或直接打字说明。系统对"取消整个办理"与"取消已确认的预约"分开处理：

- **尚未预约时取消**：提示"本次办理已停止，未提交预约"，可新建办理或查看事项。
- **已有成功预约时取消**：先展示一张 **"确认取消已预约的复诊吗？"** 确认卡，逐条列出：将取消哪个预约、会释放号源并停用关联提醒、"不另发家属消息；已发送消息保留"。请点 **确认取消预约** 才会真正取消，或点 **保留预约** 返回。取消后预约记录在事项页仍可见，状态为"已取消"。
- **从事项页直接取消**：事项页当前那条已预约的记录下面，也有一个 **「取消这次复诊」** 按钮。点它不会当场把预约删掉，而是把您送到助手页、替您把"我想取消这次复诊预约"这句话发出去，接下来仍旧走上面那张确认卡——**确认过才会真的取消**，按错了还有回头路。
- **修改已确认的预约**：完成后再想改期，可点 **「修改预约」**。系统会**保留原预约**，生成一份可改的草稿（提示"原预约仍然有效……确认新方案后才会变更原预约"），改好并确认后才变更原预约；若新号源不可用，原预约与提醒会保留。
- **返回修改日期**：点 **「返回修改」**，系统清空日期并重新询问，之前选择的号源与据此派生的信息会一并失效，避免带着旧结果确认。

> 每改动一次会影响号源、提醒或通知的关键信息，上一份"关键操作确认"就会**自动失效**，必须按新内容重新确认，防止误执行旧方案。

## 九、异常情形说明

遇到问题助手不会中断，会说明原因并给可选方案：

| 情形 | 表现与可选操作 |
| --- | --- |
| **选的日期没有号** | 若接受其他日期：列出附近日期真实可约时段供选，或重新选日期；若只要这一天：可稍后再查、主动修改日期或换医院。 |
| **上午/下午某时段没号** | 提示该时段无号，并告知另一时段最早可约时间，供切换。 |
| **想要的具体时间没号** | 提示您要的时间暂时没号，并推荐**最接近且仍可约**的时间，问是否可以。 |
| **与已有日程冲突** | 说明冲突事项（如"社区体检"）的起止时间，可改选当天其它号源、重新选日期，或明确"仍保留这个时间"。 |
| **工具执行失败 / 部分完成** | 已成功的预约会**如实保留**，未完成事项标记出来，可"补办未完成事项"，**不会重复预约、重复通知**。 |
| **说了已过去的日期** | 提示"这个日期已经过去"，请重新选。 |
| **模拟人工帮助** | 提示为演示的模拟入口，进度已保留，尚未接通真人。 |

**办理结果以模拟数据库实际执行为准**：例如"无需通知家属"只在您明确选择不通知时出现，不会在没选时伪装成完成。

## 十、安全与服务边界

- 助手**只办理复诊事务**（预约、材料、出行、提醒、通知）。对"怎么用药、药量、诊断、检查结果、是不是得了某种病、推荐药、治疗方案"等**医疗问题，一律不回答**，会提示"请咨询医生或专业医疗机构"。
- 提到**紧急情况**关键词（如胸痛、呼吸困难、昏迷、大出血、喘不上气）时，系统会**立即暂停**普通办理并提示：请立即联系身边人员、拨打 120 或寻求线下急救帮助，同时保留已有记录。暂停后旧操作不会继续执行。
- 系统只描述信息、不做医疗判断。演示数据中的"医院特色/科室擅长"仅用于办理筛选说明，不构成就医建议。
- 在"我的"页也有同样提示："本项目仅使用模拟数据，不提供诊断和用药建议。紧急情况请及时联系家属或拨打急救电话。"

## 十一、我的

点底部 **「我的」** 标签进入：

1. **用户信息卡**：当前模拟用户的姓名（如"王阿姨"）与**家属联系人**（如"女儿 小丽 · 138\*\*\*\*1234"，电话已脱敏）。
2. **适老设置**：
   - **特大字体**：打开后整页文字放大一档，更醒目（不影响任何操作）；再次点击关闭。
   - **语音朗读**：打开后，助手的新回复会自动朗读；用麦克风发起的那一轮无论开关是否打开都会朗读。默认用**手机自带的语音**（依赖浏览器能力、不联网也能用），配了云端朗读时会用云端合成，失败自动退回手机语音。音色和语速在助手页的「朗读设置」里调（见 4.7）。
3. **助手记住的事**：助手跨对话记住的偏好，整段摆在这里，一条一句人话，旁边有 **「忘掉这条」** 按钮。点一下会先问 **「确定忘掉 / 再想想」**——忘掉不可逆，按错一下不该就没了。
   - 记的是**您确认过、办成了的**复诊里沉淀下来的事：常去的医院、常去的科室、习惯的时段。填到一半还没确认的草稿**不会**被记住。
   - 换了医院再办一次，旧的会**被覆盖**，不会和新的一起留着。
   - 底部写着边界："助手只是拿它们少问您一句。真要办什么，还是您点过『确认』才算数。"——记住不等于它能替您办事。
4. 页脚再次提示系统使用模拟数据。

## 十二、常见问题（FAQ）

- **页面提示"后端服务还没有启动"怎么办？** 说明后端未运行或刚重启。请确认服务已启动后点 **「重新连接」**；也可关闭当前对话重新进入助手页。
- **提示"会话不存在或已过期"？** 后端重启或数据卷重置后旧会话失效，重新进入助手页开一段新会话即可（历史事项仍可从"事项"页查看）。
- **语音按钮点了没反应？** 当前浏览器不支持语音识别时会自动填入模拟语音文字，点发送即可继续。语音转写依赖浏览器能力，与后端无关。
- **想从上次进度继续？** 刷新或重新进入"助手"页会自动恢复上次那段对话与计划；若想从头开始，点 **「新对话」** 或 **「预约复诊」**（办理完成后此按钮变为"再次预约"）。
- **找不到刚才聊的那一段？** 点助手页顶部的 **「历史记录」**，最近几段都在里面，新的在最上面。已经结束的会话点开只能翻看，不能再说话——想接着办就点 **「开始新的一段对话」**。
- **助手怎么知道我以前去过哪家医院？** 是您上次确认办成之后它记下的（见第十一章第 3 条）。不想要就在"我的"页点 **「忘掉这条」**，忘了之后它下次不会再提。
- **它会不会拿记住的东西替我做主？** 不会。记住的只是"您以前常去哪"，用来少问一句；任何会留下记录的操作，仍然要您点过 **「确认」** 才执行。
- **点"返回修改"会丢东西吗？** 未预约时会清空日期重新询问，重新生成计划后再确认；已预约时修改走草稿流程，原预约保留，不会误丢记录。
- **进错了身份，或想换个身份再看？** 协同照护端可在「我的」页点 **「切换身份」** 回到身份选择页；就诊人端刷新页面重新进入即可再次选择身份。
- **健康记录、提醒和长期备忘在哪里看？** 都在首页底部：「提醒」看最近一条并可进列表，「长期备忘」和「健康记录」各自有入口；还没有内容时页面会引导您去跟助手说一句。
- **这是一家真医院吗？** 不是。所有医院、科室、号源、提醒与通知均在模拟数据库内执行，适合演示与操作练习。
