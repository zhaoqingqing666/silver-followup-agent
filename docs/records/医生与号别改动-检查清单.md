## 一、一句话

号源从「一个时刻的一个号」变成 **一位医生在一个时刻的一班**；预约行落**医生快照**；
助手与家属端列号时都带出「谁 · 什么号 · 多少钱」。

## 二、数据层（`1c943d4`）

### 2.1 号源表加医生维度
- 新增列：`doctor_id` / `slot_type` / `capacity` / `booked`
- `slot_type`：`NORMAL` 普通号 / `EXPERT` 专家号，**手工指定，不按职称推**
- `capacity`：专家号 3 名额 / 普通号 4 名额；`available` **降级为派生位**（`booked < capacity`）
  - ⚠️ `capacity DEFAULT 1` 不能删——测试手工 INSERT 会缺列
- 号源 id：`r-<医生id>-<日期>-<时刻>`（旧为 `r-<科室id>-<日期>-<时刻>`）
  - 唯一出处 `RollingAppointmentSlotInitializer.slotId()`

### 2.3 排班口径（DEC-026）
- 每科室每周固定 **3 个放号日**（同院内错开，周末不放）
- 放号日 **一天 4 格**：09:00 / 14:00 = **专家格**，10:30 / 15:30 = **普通格**
- 每科室 4 位医生：01 主任医师(EXPERT) / 02 主治(NORMAL) / 03 主治(NORMAL) / 04 副主任(EXPERT)
- 两院各 6 科、共 48 位医生
- `d001`（市第一医院·心内科）放号日 = **周一 / 周三 / 周五**
  - **含周三** → 时间冲突演示；**含周五** → 「附近日期」降级可取到号
- 名额比 专家 : 普通 = **6 : 8**（按条数是 2 : 2）
- ⚠️ 「下午没有专家号」这个旧场景**已废止**（14:00 现在就是专家格）；
  要演时段级降级，只能手工把那一格约满

### 2.4 预约表存医生快照
- `appointments` 加 `doctor_name / doctor_title / slot_type / fee_cents`
- **读预约不回连号源**（号源滚动重建会删行，回连会查不到或读到「现在」的值）
- 老数据 `NULL` → 前端显示「**医生信息未记录**」，**不替它编**

## 五、怎么验

### 5.1 自动化
```powershell
mvn -o -B clean test "-Dagent.model.enabled=false"     # 全量基线 427 例
```
⚠️ `HealthReportTests` 是**已知间歇性失败**（`daysAgo=0` 窗口边界）：挂哪个方法每次都换、单跑也红；
它只碰 `health_records` / `family_contacts` / `family_notifications` 三张表，与号源/预约表**零重叠**，
**别顺着它改业务代码**。

本次相关新测试：
| 测试类 | 钉住什么 |
|---|---|
| `DoctorSlotModelTests` | 排班纯函数可复现、同科室恰 2 专家 2 普通、普通名额 > 专家名额 |
| `DepartmentScheduleAndCapacityTests` | 放号日与名额口径 |
| `DoctorIntentTests` | 选医交互 R1~R6 |
| `SlotRecommenderTests` | 未点名时按医生去重 + 排序 |
| `AppointmentSubmitIdempotencyTests` | 幂等键补上号源 |
| `CareBookingServiceTests` | 代约向导每条号源都带医生 |
| `DemoSeedDataTests` | `d001` 含周三 + 周五 |

### 5.2 手工
1. **号源带医生**：对助手说「我下周三想去市第一医院心内科复诊」→ 候选按钮带医生名与号别
2. **一天 4 格**：同一天能查到 09:00 / 10:30 / 14:00 / 15:30（各不同医生）
3. **家属端渲染**：家属端「复诊预约」列表卡 / 详情 / 代约向导确认页显示「医生 · 职称 · 号别 · 挂号费」
4. **老数据兜底**：医生快照为 `NULL` 的旧预约显示「医生信息未记录」——不是空白、也不编一位医生

## 六、刻意没做的

- **不加外键、不加索引**：全库 26 张表零外键是刻意的（号源滚动重建会删行，预约靠快照说清）——别「顺手补」
- **家属端首页摘要没带医生行**
- **家属端 `hasUpcoming()` 口径没放开**（同一位老人名下只留一个进行中预约，比老人端严）——需产品拍板
- **老人端「通知家属」那 4 处文案没改**——用户明确说「都不用改」
